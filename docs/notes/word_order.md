
# Word Order: SVO and Topic-First Sentences

Mandarin usually has **SVO** word order.

```text
Subject + Verb + Object
```

| Part    | Meaning        | Example |
| ------- | -------------- | ------- |
| Subject | who does it    | 我       |
| Verb    | action         | 要       |
| Object  | thing affected | 茶       |

!!! example "Basic SVO"
    {{zh:我要茶。}}  
    Wǒ yào chá.  
    I want tea.  

    **我** is the subject, **要** is the verb, and **茶** is the object.

But Mandarin often puts known information first. This is called a **topic-first** sentence.

```text
Topic + Subject + Verb
```

The topic is the thing the sentence is about.

## Basic SVO order

These are normal SVO sentences.

!!! example "I drink tea"
    {{zh:我喝茶。}}  
    Wǒ hē chá.  
    I drink tea.  

    This is basic SVO word order.


!!! example "He buys books"
    {{zh:他买书。}}
    Tā mǎi shū.
    He buys books.

    **他** is the subject, **买** is the verb, and **书** is the object.

!!! example "I want this one"
    {{zh:我要这个。}}
    Wǒ yào zhège.
    I want this one.

    This is the neutral word order.

## Topic-first order

In Mandarin, a known object can often come first.

```text
Object / Topic + Subject + Verb
```

This does not mean Mandarin is basically SOV. It means the object has become the topic.

!!! example "This one, I want"
    {{zh:这个我要。}}
    Zhège wǒ yào.
    This one, I want.

    **这个** comes first because it is the topic.
    
!!! example "That one, I do not want"
    {{zh:那个我不要。}}
    Nàge wǒ bù yào.
    That one, I do not want.

    The speaker is talking about **那个**.

!!! example "Tea, I drink"
    {{zh:茶我喝。}}
    Chá wǒ hē.
    Tea, I drink.

    This can contrast tea with something else.

!!! example "This book, I have read"
    {{zh:这本书我看了。}}
    Zhè běn shū wǒ kàn le.
    I have read this book.

    Literally: “This book, I read.”

## Why use topic-first order?

Topic-first order is common when the thing is already known.

Compare:

!!! example "Neutral SVO"
    {{zh:我喜欢这个。}}
    Wǒ xǐhuan zhège.
    I like this one.

    This is a plain sentence.


!!! example "Topic-first"
    {{zh:这个我喜欢。}}
    Zhège wǒ xǐhuan.
    This one, I like.

    This sounds like the speaker is choosing or comparing.


Another pair:

!!! example "Neutral SVO"
    {{zh:我知道这件事。}}
    Wǒ zhīdào zhè jiàn shì.
    I know this matter.

    This is basic SVO.


!!! example "Topic-first"
    {{zh:这件事我知道。}}
    Zhè jiàn shì wǒ zhīdào.
    This matter, I know.

    **这件事** is the topic.


## With 都

The word **都** usually comes before the verb or adjective.

```text
都 + verb / adjective
```

So when saying “both,” the two known things often come before **都**.

!!! example "Both are good"
    {{zh:两个都好。}}
    Liǎng gè dōu hǎo.
    Both are good.


    **都** comes before the adjective **好**.


!!! example "Both came"
    {{zh:两个都来了。}}
    Liǎng gè dōu lái le.
    Both came.


    **都** comes before the verb **来**.


!!! example "I want both of these two"
    {{zh:这两个我都要。}}
    Zhè liǎng gè wǒ dōu yào.
    I want both of these two.


    Literally: “These two, I both want.”


!!! example "I want both"
    {{zh:两个我都要。}}
    Liǎng gè wǒ dōu yào.
    I want both.


    This is used when the two things are already clear.


!!! example "I want both"
    {{zh:我两个都要。}}
    Wǒ liǎng gè dōu yào.
    I want both.


    This is a compact spoken form. A clearer full form is **这两个我都要**.


## Two different meanings

Do not confuse **two** and **both**.

!!! example "I want two"
    {{zh:我要两个。}}
    Wǒ yào liǎng gè.
    I want two.


    This only gives the number.


!!! example "I want both"
    {{zh:这两个我都要。}}
    Zhè liǎng gè wǒ dōu yào.
    I want both of these two.


    This means the two things are already known, and the speaker wants both.


## Daily speech examples

Topic-first order is common in daily speech.

!!! example "This one, I know"
    {{zh:这个我知道。}}
    Zhège wǒ zhīdào.
    I know this one.


    The speaker is talking about **这个**.


!!! example "That one, I do not know"
    {{zh:那个我不知道。}}
    Nàge wǒ bù zhīdào.
    I do not know that one.


    **那个** is the topic.


!!! example "Chinese, I can speak a little"
    {{zh:中文我会说一点。}}
    Zhōngwén wǒ huì shuō yì diǎn.
    I can speak a little Chinese.


    Literally: “Chinese, I can speak a little.”


!!! example "This character, I can write"
    {{zh:这个字我会写。}}
    Zhège zì wǒ huì xiě.
    I can write this character.


    **这个字** comes before the subject.


!!! example "Rice, I have eaten"
    {{zh:饭我吃了。}}
    Fàn wǒ chī le.
    I have eaten.


    Literally: “Food, I ate.” This is common in daily speech.


## More formal examples

Topic-first order is also common in careful or formal speech.

!!! example "This matter, I do not know"
    {{zh:这件事，我不知道。}}
    Zhè jiàn shì, wǒ bù zhīdào.
    I do not know about this matter.


    In writing, a comma is often used after the topic.


!!! example "This question, we will talk about tomorrow"
    {{zh:这个问题，我们明天再说。}}
    Zhège wèntí, wǒmen míngtiān zài shuō.
    We will talk about this question tomorrow.


    **这个问题** is the topic.


!!! example "This method, I agree with"
    {{zh:这个办法，我同意。}}
    Zhège bànfǎ, wǒ tóngyì.
    I agree with this method.


    This is topic-first order.


## Main patterns

| Pattern                        | Example         | Meaning                            |
| ------------------------------ | --------------- | ---------------------------------- |
| Subject + Verb + Object        | {{zh:我要茶。}}     | I want tea.                        |
| Topic + Subject + Verb         | {{zh:茶我要。}}     | Tea, I want.                       |
| Topic + Subject + 不 + Verb     | {{zh:这个我不知道。}}  | This, I do not know.               |
| Topic + Subject + 都 + Verb     | {{zh:这两个我都要。}}  | I want both of these two.          |
| Topic + Subject + 都 + 不 + Verb | {{zh:这两个我都不要。}} | I do not want either of these two. |
| Topic + Subject + 会 + Verb     | {{zh:中文我会说。}}   | I can speak Chinese.               |

!!! tip
    Mandarin is usually **SVO**, but it is also very topic-friendly. Known things often come first.
