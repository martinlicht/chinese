# Reading Out Phone Numbers in Chinese

When reading phone numbers in Mandarin Chinese, each digit is usually read separately.
Read the number digit by digit. Do **not** read the number as a full mathematical number.
In addition, there are some differences in pronunciation.


## Digits Used in Phone Numbers

| Digit | Chinese | Pinyin | Notes |
| ----- | ------- | ------ | ----- |
| 0 | 零 | líng | zero |
| 1 | 幺 | yāo | used instead of 一 yī in phone numbers |
| 2 | 二 | èr | not 两 liǎng |
| 3 | 三 | sān | |
| 4 | 四 | sì | |
| 5 | 五 | wǔ | |
| 6 | 六 | liù | |
| 7 | 七 | qī | |
| 8 | 八 | bā | |
| 9 | 九 | jiǔ | |

In ordinary counting, **1** is read **一 yī**. In phone numbers, addresses, ID numbers, and codes, **1** is often read **幺 yāo**. This makes it easier to distinguish from **七 qī**, especially over the phone.

So:

| Context | 1 is read as |
| ------- | ------------ |
| Counting | 一 yī |
| Phone numbers | 幺 yāo |

## Example Phone Numbers

| Number | Mandarin Reading |
| ------ | ---------------- |
| 110 | yāo yāo líng |
| 120 | yāo èr líng |
| 138 0000 5678 | yāo sān bā líng líng líng líng wǔ liù qī bā |
| 021 5555 8888 | líng èr yāo wǔ wǔ wǔ wǔ bā bā bā bā |
| 138 4567 9021 | yāo sān bā  sì wǔ liù qī  jiǔ líng èr yāo |
